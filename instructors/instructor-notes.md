This tutorial builds on the [Setting Up Your EIC Environment](https://eic.github.io/tutorial-setting-up-environment/)
tutorial: every episode assumes learners can already start `eic-shell`.

## Before the session

- Ask learners to complete the [Setup](../learners/setup.md) page in advance, in particular building
  a development copy of EICrecon, which can take a long time.
- Have learners generate or download a small simulated data file ahead of time so the live session
  is not spent waiting on `ddsim` or large downloads.

## Timing

- Episodes 03 (end-user plugin) and 04 (JFactory) are the longest and most hands-on; budget the
  bulk of the session for them.
- Episodes 03 and 04 open with a note that parts of the material are somewhat outdated and some
  commands may not function. If learners only need to analyze already-reconstructed data, they can
  work directly from the output ROOT file instead of building a plugin.
